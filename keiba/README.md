# 🐎🃏 馬主カード — 競馬×カードゲーム（MVP）

カードを集めて馬を作り、育て、レースに出すだけで楽しめるブラウザ競馬カードゲーム。

## 遊び方

`keiba/index.html` をブラウザで開くだけ（ビルド不要・サーバー不要・外部ライブラリなし）。
データはブラウザの localStorage に自動保存されます。

1ファイル版：`python3 keiba/build.py` で `keiba/dist/keiba-card-game.html`（CSS・JSを全部埋め込んだHTML）を作れます。
このファイル1つだけで遊べるので、配布やスマホへの送付に便利です。

```
カード収集 → 配合 → 競走馬誕生 → 調教 → スキル編成 → レース（オート） → 報酬カード → さらに配合
```

## 実装済み（設計図 Phase 1〜8）

| Phase | 内容 |
|---|---|
| 1 | 競走馬データ・カード表示・厩舎（最大6頭） |
| 2 | 配合（父カード＋母カード、遺伝傾向・相性・個体差、配合予想、親スキルの継承） |
| 3 | 調教5種＋軽め＋休養、おまかせ調教、成長タイプ（早熟/普通/晩成）、年齢、レベル、調子・疲労、アイテム |
| 4 | スキル3枠・自動発動（条件・発動率は賢さ依存・脚質不一致は効果60%・優先順位） |
| 5 | 5路線（スプリンター/マイラー/クラシック/牝馬クラシック/王道古馬）、新馬〜GⅠ、出走条件（年齢・性別・勝利数） |
| 6 | 賞金・経験値・カード報酬（格ごとのレア度確率）、カード図鑑（未入手はシルエット）、ショップ |
| 7 | localStorage セーブ（`save.js` に分離。差し替えでサーバー保存へ移行可） |
| 8 | 引退・殿堂入り（GⅠ 3勝 or 通算10勝）、称号、重賞勝ち馬は配合カード化して次世代へ |

ほか：初心者ミッション10段階、チュートリアルガイド、用語解説「？」ボタン、スマホ向け下部ナビ。

### v3 JRAカレンダー

| 機能 | 内容 |
|---|---|
| ゲーム内カレンダー | 1年＝12か月×4週（48週）。全馬共通の日付で、馬は1週に1回だけ行動（調教・レース・休養）。「次の週へ」で未行動の馬はおまかせ調教。「4週すすめる」は目標の重賞の週と年明けで止まる |
| 実在のJRA重賞 | 年間の重賞（GⅠ・GⅡ・GⅢ 約110レース）を実際の時期・競馬場・距離・出走条件で収録（1か月＝4週に丸めて配置）。皐月賞は4月、日本ダービーは5月、有馬記念は12月など |
| クラス制 | 新馬 → 未勝利 → 1勝 → 2勝 → 3勝クラス → オープン。条件戦は毎週開催（2歳新馬戦は6月開幕、3歳未勝利戦は9月まで） |
| 優先出走権 | トライアル上位で本番の出走権（弥生賞・スプリングS→皐月賞、チューリップ賞→桜花賞、青葉賞→ダービー、神戸新聞杯→菊花賞 など） |
| 1月1週（年明け） | 全馬が1歳年をとる（JRAと同じく1月1日が誕生日扱い）、前年の成績から年度表彰（JRA賞）と賞金ボーナス、6歳で引退、お年玉（賞金＋カードパック） |
| 季節 | 梅雨（6〜7月）は馬場が重くなりやすい |
| 称号 | 三冠馬・牝馬三冠・春古馬三冠・秋古馬三冠、年度代表馬など |

ゲーム開始は「1年目 6月1週」（2歳新馬戦の開幕週）。レース名・時期は実在のものですが、出走馬（ライバル）はすべて架空です。

## レース計算と表示の分離

`Race.simulate(race, entrants, ground)` は DOM に触れない純粋な計算で、以下を返します。

- `finish` … 着順・タイム・着差
- `events` … 実況（チェックポイントごとの順位・馬身差、スキル発動、先頭交代など）
- `frames` … 0.5秒ごとの全馬の位置（2Dトラック表示に使用）

`RaceView`（ui.js）は結果を受け取って再生するだけで、計算はしません。
結果は再生前に確定・保存されるので、途中でリロードしても結果は変わりません。
`RaceView` はレース内の時計で `frames`（0.5秒ごとの位置）を補間し、3D（`Race3D`）または2Dトラック・実況・順位表を同時に動かします。

## バランス調整のポイント

- NPCの強さ：`GAME_DATA.grades[*].npc`（data.js）、2歳・3歳限定戦の補正は `Race.ageAdjust`
- 重賞の日程・条件：`GAME_DATA.races`（data.js）、条件戦の生成：`Race.conditionRaces`
- レース中の速度・体力：`race.js` の `styleMult` / `styleCost` / `SKILL_SCALE` など
- 報酬レア度：`GAME_DATA.dropTable`
- 配合の個体差：`Breeding.VARIANCE`
- リーグのCPUの強さ・能力上限：`GAME_DATA.leagues`
