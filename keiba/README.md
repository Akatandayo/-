# 🐎🃏 馬主カード — 競馬×カードゲーム（MVP）

カードを集めて馬を作り、育て、レースに出すだけで楽しめるブラウザ競馬カードゲーム。

## 遊び方

`keiba/index.html` をブラウザで開くだけ（ビルド不要・サーバー不要・外部ライブラリなし）。
データはブラウザの localStorage に自動保存されます。

1ファイル版：`python3 keiba/build.py` で `keiba/dist/keiba-card-game.html`（CSS・JSを全部埋め込んだHTML）を作れます。
このファイル1つだけで遊べるので、配布やスマホへの送付に便利です。

```
カード収集 → 配合 → 競走馬誕生 → 調教 → スキル編成 → レース（オート） → 報酬カード → さらに配合
```

## 実装済み（設計図 Phase 1〜8）

| Phase | 内容 |
|---|---|
| 1 | 競走馬データ・カード表示・厩舎（最大6頭） |
| 2 | 配合（父カード＋母カード、遺伝傾向・相性・個体差、配合予想、親スキルの継承） |
| 3 | 調教5種＋軽め＋休養、おまかせ調教、成長タイプ（早熟/普通/晩成）、年齢、レベル、調子・疲労、アイテム |
| 4 | スキル3枠・自動発動（条件・発動率は賢さ依存・脚質不一致は効果60%・優先順位） |
| 5 | 5路線（スプリンター/マイラー/クラシック/牝馬クラシック/王道古馬）、新馬〜GⅠ、出走条件（年齢・性別・勝利数） |
| 6 | 賞金・経験値・カード報酬（格ごとのレア度確率）、カード図鑑（未入手はシルエット）、ショップ |
| 7 | localStorage セーブ（`save.js` に分離。差し替えでサーバー保存へ移行可） |
| 8 | 引退・殿堂入り（GⅠ 3勝 or 通算10勝）、称号、重賞勝ち馬は配合カード化して次世代へ |

ほか：初心者ミッション10段階、チュートリアルガイド、用語解説「？」ボタン、スマホ向け下部ナビ。

### v2 追加機能

| 機能 | 内容 |
|---|---|
| 2Dレース演出（Phase 9） | `frames` を補間して馬が走るトラック表示。先頭馬を追うカメラ、残り距離、ゴール板、スキル発動エフェクト。順位表もリアルタイム更新 |
| リーグ戦（Phase 10） | CPU馬主7人と8頭立て。ブロンズ（能力上限70）／シルバー（85）／ゴールド（無制限）。順位でレーティング増減、上位リーグ解放 |
| フレンド対戦 | 馬を「対戦コード」（`UMA1.`〜、チェックサム付き）に書き出し、フレンドのコードを読み込んで対戦。コース・能力上限を選べる。サーバー不要 |
| 特殊配合 | 黄金配合（9種、低レアの組み合わせもあり）、奇跡の血量（共通の先祖がいるインブリード）、脚質一致、名馬の結晶。発見した黄金配合はリストに記録 |
| 血統表 | 3代血統表（父・母・祖父母）。殿堂馬カードが先祖情報を引き継ぐので、自家生産の血統がつながる |
| カードパック | ベーシック／プレミアム（SR以上確定）／血統パック（種牡馬・繁殖牝馬のみ） |
| 記録・ランキング | オーナー成績、獲得賞金・勝利数・GⅠ勝利数ランキング、コースレコード |

未実装：オンラインセーブ、リアルタイムのサーバー対戦、イベント、ギルド。

## ファイル構成

```
keiba/
  index.html
  build.py         1ファイル版HTMLを作るスクリプト
  dist/            1ファイル版の出力先
  css/style.css
  js/
    data.js        カード・スキル・レース・ミッション・用語などの静的データ
    save.js        保存処理（localStorage）
    card.js        Util（乱数・表示ヘルパー）とカード検索・報酬抽選
    player.js      プレイヤーデータ・所持カード・ミッション
    horse.js       競走馬の共通ロジック（評価・年齢・成長・おすすめ路線）
    breeding.js    配合
    training.js    調教・おまかせ・アイテム
    skill.js       スキル装備と発動判定
    race.js        レース計算（純粋関数）と報酬反映
    pvp.js         リーグ戦・対戦コード（フレンド対戦）
    halloffame.js  引退・殿堂・殿堂馬カード
    ui.js          画面描画（UI）とレース再生（RaceView）
    main.js        起動とプレイヤー操作（App）
```

## レース計算と表示の分離

`Race.simulate(race, entrants, ground)` は DOM に触れない純粋な計算で、以下を返します。

- `finish` … 着順・タイム・着差
- `events` … 実況（チェックポイントごとの順位・馬身差、スキル発動、先頭交代など）
- `frames` … 0.5秒ごとの全馬の位置（2Dトラック表示に使用）

`RaceView`（ui.js）は結果を受け取って再生するだけで、計算はしません。
結果は再生前に確定・保存されるので、途中でリロードしても結果は変わりません。
`RaceView` はレース内の時計で `frames`（0.5秒ごとの位置）を補間し、2Dトラック・実況・順位表を同時に動かします。

## バランス調整のポイント

- NPCの強さ：`GAME_DATA.grades[*].npc`（data.js）
- レース中の速度・体力：`race.js` の `styleMult` / `styleCost` / `SKILL_SCALE` など
- 報酬レア度：`GAME_DATA.dropTable`
- 配合の個体差：`Breeding.VARIANCE`
- リーグのCPUの強さ・能力上限：`GAME_DATA.leagues`
