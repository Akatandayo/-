# BLOCK FLEET — 艦船建造海戦ゲーム

ブロックを組み合わせて自分だけの軍艦を設計し、3Dの海で自動砲撃の海戦を行うブラウザゲームです。
iPhone / Android / PC のブラウザでそのまま動きます。

- `BlockFleet.html` … **1ファイルで完結・オフライン対応版**（ダウンロードして開くだけ）
- `index.html` … 開発用（Three.js をCDNから読み込み）

## ゲームの流れ
建造ドックで艦を設計 → 海戦で **資金(G)** と **経験値** を獲得 → **工廠（ショップ）** で兵装を購入 → さらに強い艦へ。

- 基本ブロック（船体・甲板・装甲・斜め・上部構造・機関・艦橋・装飾など）は**無料・無制限**
- 兵装・特殊設備は工廠で**1個ずつ購入**（重装甲・浮力ブロックは一度の解放で使い放題）。買ったパーツは何隻の設計にも使える／半額で売却可
- 経験値で**階級**（少尉〜元帥）が上がり、大口径砲・ミサイル・特殊兵器が解放。昇進ボーナス・ログインボーナスあり

## 兵装（約200種類）
- 主砲: 7.6cm〜100cm の27口径 × 単装/連装/三連装/四連装（小口径・中口径・大口径・超大口径）
- 近代砲: 57mm〜203mm速射砲、155mm先進砲（曲射）
- 機銃: 7.7mm〜57mm × 単装〜四連装 / 高角砲: 8cm・10cm・12.7cm（長砲身あり）/ CIWS（20mm・30mm・35mm・レーザー）
- 対空ミサイル: 短SAM・SeaRAM・中距離・発展型・長距離・艦隊防空
- 対艦ミサイル: 小型・標準・4連装・超音速・大型・巡航・極超音速・対艦弾道ミサイル
- 魚雷: 45/53/61cm × 2〜8連装、酸素魚雷・誘導魚雷・ロケット推進魚雷・超大型魚雷
- 特殊兵器: 迫撃砲・榴弾砲（曲射）・噴進砲・多連装ロケット・レールガン（3種）・レーザー（3種）・プラズマ砲・荷電粒子砲
- 航空: 飛行甲板＋格納庫（戦闘機・爆撃機・雷撃機・ジェット攻撃機・ジェット戦闘機）、ヘリ甲板＋哨戒ヘリ
- 設備: 大型機関・ガスタービン・原子炉・レーダー・高性能レーダー・測距儀・応急修理室・自動装填装置・強化弾薬庫・ECM

## 海戦
- 艦の**耐久値(HP)**＝積んだブロックの耐久の合計。**ブロックは壊れない**（焦げ跡・火災・沈み込みで損傷を表現）。HP 0 で撃沈
- 砲弾は最初に当たったブロックで受け止め、装甲は貫通力に応じてダメージを軽減（跳弾）
- 照準・射撃は全自動。操舵は自動／手動。敵艦タップで集中攻撃、レーダー（ミニマップ）、ダメージ表示

## モード
- **キャンペーン**（全12海戦、初回報酬2倍、★3評価）
- **連続海戦**（ウェーブ制、ウェーブごとに報酬とHP回復、自己ベスト記録）
- **フリー海戦**（好きな艦同士で対戦、報酬50%）
- **試運転**（建造ドックから標的艦に試し撃ち）
