# BLOCK FLEET — 艦船建造海戦ゲーム

ブロックを組み合わせて自分だけの軍艦を設計し、3Dの海で自動砲撃の海戦を行うブラウザゲームです。
iPhone / Android / PC のブラウザでそのまま動きます（Three.js 使用、ビルド不要）。

## 遊び方
`blockfleet/index.html` をブラウザで開くだけ（GitHub Pages で公開すると `https://<ユーザー名>.github.io/<リポジトリ>/blockfleet/` で遊べます）。

- **建造ドック**: 船体・甲板・装甲・斜めブロック、機関・艦橋・煙突・マスト、各種兵装を配置。左右対称配置、回転、元に戻す、断面表示、保存/読込、共有コード対応。
  - 砲雷: 12.7cm砲 / 15.5cm三連装砲 / 20cm連装砲 / 35.6cm連装砲 / 46cm三連装砲 / 魚雷
  - 対空・誘導: 機銃 / 12.7cm高角砲（対空・対艦両用）/ CIWS / 対空ミサイル / 対艦ミサイル（誘導・迎撃可能）
  - 航空: 飛行甲板（10個以上で空母化）/ 戦闘機・爆撃機・雷撃機の格納庫（各2機）
- **編集を楽に**: 範囲設置／範囲削除、船体自動生成（全長・幅・深さ・艦首形状・装甲帯・空母化）、塗装（船体色・甲板・喫水線下）、対艦火力・対空火力・防御のS〜E評価。
- **浮力計算**: 水面下のブロック体積で浮力を計算。重すぎると沈み、重量バランスが偏ると傾く。喫水線・速力・コストをリアルタイム表示。
- **海戦**: 砲撃・照準・偏差射撃は全自動。弾道は放物線。ブロック単位で破壊され、喫水線下の破孔から浸水 → 浮力を失うと撃沈。操艦は自動／手動（WASD・矢印・画面ボタン）を切替可能。
- **空母と艦載機**: 艦載機は自動で発艦・編隊を組んで攻撃し、着艦して補給・再出撃。戦闘機は空戦と機銃掃射、爆撃機は急降下爆撃、雷撃機は低空雷撃。対空砲火は弾幕（近接信管）で迎撃。
- **海戦の操作と表示**: 敵艦タップで攻撃目標指定、レーダー（ミニマップ）、ダメージ数値・撃沈・迎撃のポップアップ、空母甲板の駐機表示、命中率・撃墜数・MVPの戦績表示。
- **キャンペーン**: 各海戦に★3評価（勝利／撃沈されず勝利／艦隊コスト基準以下）。駆逐艦から空母機動部隊、ミサイル艦、超弩級戦艦まで全10海戦。**フリー海戦**: 自軍・敵軍を最大4隻ずつ自由に編成。

- **設定**: 画質（高/中/低）、効果音、環境音（波の音）、キャンペーン進行リセット。
