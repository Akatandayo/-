# BLOCK FLEET — 艦船建造海戦ゲーム

ブロックを組み合わせて自分だけの軍艦を設計し、3Dの海で自動砲撃の海戦を行うブラウザゲームです。
iPhone / Android / PC のブラウザでそのまま動きます（Three.js 使用、ビルド不要）。

## 遊び方
`blockfleet/index.html` をブラウザで開くだけ（GitHub Pages で公開すると `https://<ユーザー名>.github.io/<リポジトリ>/blockfleet/` で遊べます）。

- **建造ドック**: 船体・甲板・装甲・斜めブロック、機関・艦橋・煙突・マスト、機銃・12.7cm砲・20cm連装砲・46cm三連装砲・魚雷を配置。左右対称配置、回転、元に戻す、断面表示、保存/読込、共有コード対応。
- **浮力計算**: 水面下のブロック体積で浮力を計算。重すぎると沈み、重量バランスが偏ると傾く。喫水線・速力・コストをリアルタイム表示。
- **海戦**: 砲撃・照準・偏差射撃は全自動。弾道は放物線。ブロック単位で破壊され、喫水線下の破孔から浸水 → 浮力を失うと撃沈。操艦は自動／手動（WASD・矢印・画面ボタン）を切替可能。
- **キャンペーン**: 駆逐艦から超弩級戦艦まで全7海戦。**フリー海戦**: 自軍・敵軍を最大4隻ずつ自由に編成。
