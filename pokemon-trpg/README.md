# ポケモンTRPG KP補助ツール

[ポケットモンスターTRPGルールブック ver.β2.4](https://heni-poke.hatenablog.com/entry/2018/04/02/213652) 準拠の KP(GM) 用計算ツールです。`index.html` をブラウザで開くだけで動きます(ビルド不要)。

- 初代(赤緑)151匹・165技を収録(赤緑のタイプ・種族値・技性能・覚える技)。設定で最新世代の数値にも切り替え可能
- 行動パネル：行動前判定(麻痺/眠り/氷/混乱/メロメロ) → 回避判定 → ダメージ(急所の連鎖、連続技、固定ダメージ技、範囲技2/3、壁) → 追加効果 → 強化フェイズ
- ランク変動・状態異常・PP・道具・行動後の毒/火傷ダメージ・行動順
- 捕獲判定・逃走判定
- ココフォリア用のキャラクター駒(HP・PP・ボーナス値・チャットパレット)をクリップボードにコピー
- データはブラウザに自動保存。バックアップはテキストでコピー/復元
