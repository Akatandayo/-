# Network // アカルア ― 迷い人の依頼帳

CoC6版のキャラクター（白石ハルカ・電子独・電子紅葉）が暮らす【Network】を舞台にした、ノベルADV＋コマンドRPG。
「もしプレイヤーが今の【Network（アカルア）】に迷い込んだら」がコンセプト。

## 遊び方
`akarua/index.html` をブラウザで開く（GitHub Pages なら `/akarua/`）。

## ファイル
- `index.html` … エンジン（画面・ダイス・戦闘・セーブ）
- `scenario.js` … シナリオ・依頼・会話・敵・エンディング（台詞の書き方は冒頭コメント参照）
- `img/` … 立ち絵（背景透過済み）
