# 峠 SPIRITS — 走り屋ストーリーRPG（峠・ドリフト編）

日本の走り屋文化をテーマにした、ブラウザで遊べるストーリーRPGレースゲームです。
車は **Top Drives** のカード（日本メーカー 939枚：日産・マツダ・ホンダ・スバル・三菱・スズキ・アキュラ・インフィニティ）を使用します。

`touge/index.html` を開くだけで遊べます（ビルド不要。GitHub Pages なら `/touge/`）。

## 遊び方

| 操作 | タッチ | キーボード |
|---|---|---|
| ドリフト進入 | リングが白い輪に重なった瞬間に **押す** | Space / Z / ↓ |
| ドリフト脱出 | 押したままコーナーを抜け、出口のリングで **離す** | キーを離す |
| ニトロ (N₂O) | ゲージ満タンで右下ボタン | X / N / Shift |
| カメラ切替 | 📷 | C |
| ポーズ | ❚❚ | Esc / P |

- 判定は **PERFECT / GREAT / GOOD / MISS**。PERFECT進入でコーナー速度が最大+13%、PERFECT脱出で立ち上がりブースト。
- MISS はガードレール接触（火花＋大減速）。S字は「離す→すぐ押す」の切り返しリズム。
- 駆動方式で特性が変わる：**RWD** ドリフト角大・スコア×1.2 ／ **4WD** 判定幅×1.25 ／ **FWD** 判定幅×1.12。
- 雨のコースはタイヤ種別ごとにグリップ低下（スリックは大幅ダウン）。
- 後ろの車がスリップストリームに入ると加速＆ニトロ回復。コーナーでは追い抜けず「ブロック」される。

## モード

- **ストーリー**：全4章（霧坂峠 / 紅葉坂 / 龍神スカイライン / 天狗峠）。会話シーン、バトル、後追いバトル（ゴール差1秒以内で勝ち）、出走条件（RQ制限・FR限定）付きイベント、各章ボス。
- **フリーバトル**：解放済みコースで野良バトル（EASY/NORMAL/HARD）やタイムアタック。賞金稼ぎ用。
- **オンライン対戦**：PeerJS (WebRTC) による P2P 対戦。ルームを作って5文字のコードを相手に伝えるだけ。
- **ガレージ**：カードコレクション、3Dプレビュー、チューニング（エンジン / 軽量化 / 足回り 各3段階＝Top Drives風 "333"）、重複売却。
- **カードショップ**：ブロンズ〜プラチナパック。開封演出付き。

## ファイル構成

```
touge/
  index.html        エントリポイント
  css/style.css     UI / HUD / カード / 演出
  js/cards.js       Top Drives カードデータ（topdrives.club より取得）
  js/data.js        コース・テーマ・キャラクター・ストーリー・パック
  js/sim.js         レースシミュレーション（描画なし。Node でもテスト可能）
  js/race.js        three.js による3D描画・HUD・入力・演出
  js/audio.js       WebAudio 合成サウンド（エンジン音・スキール音・ユーロビート風BGM）
  js/net.js         オンライン対戦（PeerJS）
  js/game.js        RPG部分（セーブ・ストーリー・ガレージ・ショップ・対戦ロビー）
```

外部ライブラリ：three.js r128（cdnjs）、PeerJS 1.5.5（jsDelivr）。セーブは localStorage。
